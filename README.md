# Сервер картинок 2.0

Веб-сервис загружает изображения, сохраняет их метаданные в PostgreSQL, показывает список с пагинацией, позволяет искать и удалять изображения.

## Запуск

Из папки проекта выполните:

```powershell
docker compose up --build -d
```

Приложение доступно напрямую по адресу `http://localhost:8000`.
Через Nginx приложение доступно по адресу `http://localhost:8080`.

Остановка контейнеров:

```powershell
docker compose down
```

Файлы изображений сохраняются в `images/`, логи — в `logs/`, резервные копии — в `backups/`. Данные PostgreSQL хранятся в Docker-томе `db_data`.

Допустимые форматы: `jpg`, `jpeg`, `png`, `gif`.

## Маршруты

- `GET /` — страница загрузки и количество изображений.
- `POST /upload` — сохранение изображения и его метаданных.
- `GET /images-list` — список изображений.
- `GET /images-list?page=2` — вторая страница списка, по 10 изображений на странице.
- `GET /images-list?q=photo` — поиск по оригинальному имени.
- `POST /images-filter` — форма поиска с переходом на страницу списка.
- `GET /images/<имя_файла>` — просмотр или скачивание изображения.
- `POST /delete/<id>` — удаление записи из PostgreSQL и файла с диска.

Таблица `images` содержит идентификатор, сгенерированное имя, оригинальное имя, размер в байтах, время загрузки и тип файла.

## Резервное копирование

После запуска контейнеров выполните из папки проекта:

```powershell
python backup.py
```

Скрипт вызывает `pg_dump` внутри контейнера PostgreSQL и создаёт файл вида `backups/backup_2026-10-31_153000.sql`. Результат и ошибки записываются в `logs/app.log`.

Аналогичная команда без скрипта:

```powershell
docker compose exec -T db pg_dump -U postgres -d images_db > backups/backup_2026-10-31_153000.sql
```

Для восстановления базы остановите приложение или временно отключите его, затем выполните:

```powershell
Get-Content backups\backup_2026-10-31_153000.sql | docker compose exec -T db psql -U postgres -d images_db
```

Если база была создана на предыдущем этапе с таблицей `documents`, `init.sql` переносит её записи в `images` при первоначальной инициализации нового тома. Для уже существующего тома примените схему вручную:

```powershell
docker compose exec db psql -U postgres -d images_db -f /docker-entrypoint-initdb.d/init.sql
```

## Логирование

Операции загрузки, удаления, ошибки подключения и создание резервной копии записываются в `logs/app.log` с датой и временем.
